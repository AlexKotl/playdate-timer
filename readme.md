# Productivity Rabbit

> Time Tracker for life

## Overview

Basic activities are:

- work
- meeting
- learning
- creativity

## Description

![alt text](https://raw.githubusercontent.com/AlexKotl/playdate-timer/refs/heads/main/design/screenshots/3.png?token=GHSAT0AAAAAACZR5HRO5T2AV6MVOY5YSA6IZ3HIIWQ)

Productivity Rabbit is a time tracking app with game elements, that aimed to improve your productivity. 

- track time, grouped by 4 different activities
- 24-hours activity overview
- analize spent time by days and weeks
- earn point for tracked time and upgrade rabbit's house

This app has 3 screens: Timer Tracker, Reports, Rabbit's hole.

**Time Tracker**. Select one of four activitys you're doing (work, meetings, learning, creativity), press A to start timer. One session might be maximum of 90 minutes. Don't forget to make a breaks! At the bottom of a screet you'll see **24h progress** bar, that will help you to quickly analyze how performent are you durting current day.

**Reports**. Pres Up or Down to select week. You'll see bar charts, with different color representation of different activities. To find out more about tracked time on specific day - use Left and Right arrows to select a date. Time will be displayed in top right corner.

**Rebbit's hole**. In the end of every day you will *earn* money for tracked time. Improve life of the Rabbit with buying new furniture and other things. This was done to help you get used to time tracking and make you more productive.
