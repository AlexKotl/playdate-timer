# Productivity Rabbit

> 🐰 Productivity Rabbit is a time tracking app for PlayDate, that aimed to improve your work productivity by better time management.

<img src='https://github.com/AlexKotl/playdate-timer/blob/main/design/screenshots/3.png?raw=true' width=400 />


## Overview

- Track time across four activity types
- 24-hour activity overview – see your day at a glance
- Analyze your time by days and weeks with reports
- Build Rabbit’s dream burrow – earn points for tracking time and upgrade Rabbit’s cozy home! 

<img src='https://github.com/AlexKotl/playdate-timer/blob/main/design/design%20elements/rabbit-gif-for-web.gif?raw=true' />


### How to use 🐾

Press **A** to start timer, press A again to stop. Use arrows to select activity type.

Press **B** to switch to report screen. Use left/right arrows to see activity details by day. Use up/down arrows to navigate by weeks.

<hr>

**Time Tracker**. Select one of four activitys you're doing (work, meetings, learning, creativity), press A to start timer. One session might be maximum of 90 minutes. Don't forget to make a breaks! At the bottom of a screet you'll see 24h progress bar, that will help you to quickly analyze how performent are you durting current day.

<img src='https://github.com/AlexKotl/playdate-timer/blob/main/design/screenshots/5.png?raw=true' />

<hr>

**Reports**. Press Up or Down to select week. You'll see bar charts, with different color representation of different activities. To find out more about tracked time on specific day - use Left and Right arrows to select a date. Time will be displayed in top right corner.

<img src='https://github.com/AlexKotl/playdate-timer/blob/main/design/screenshots/6.png?raw=true' />

<hr>

**Rabbit's hole**. In the end of every day you will earn money for tracked time. Spend them on furniture, decorations, and cozy upgrades to make Rabbit’s burrow the ultimate productivity paradise!

<img src='https://github.com/AlexKotl/playdate-timer/blob/main/design/screenshots/9.png?raw=true' />


## Building and running

To build/run in emulator:
- Install PlayDate SDK
- Run `./build.sh`. This will build and launch emulator.
- VSCode will rebuild each time on file save. Edit .vscode/settings.json to change this. `emeraldwalk.runonsave` addon required for auto build.
